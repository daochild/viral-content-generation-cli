Viral Content Generator UI

A front-end command builder and quick reference for photo prompts, video prompts, and Gemini text-to-speech generation.

Bun + TypeScript CLI Gemini / OpenAI / Ollama KlingAI Video Gemini TTS (WAV)

Photo Mode

Create social-ready image prompts. Use --gen to generate actual images with Gemini or Stability (via Ollama workflow).

Video Mode

Generate TikTok-unique prompts and optionally render videos. Current CLI output media path is tracked per run.

TTS Mode

Gemini-only speech synthesis with voice selection. Outputs .wav PCM 16-bit 24kHz mono files.
